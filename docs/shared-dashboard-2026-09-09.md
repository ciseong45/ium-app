# 공동 사역 대시보드 — 2026-09-09

## 구성

- 루트 대시보드에서 여름순 신청 배너 제거. 신청 페이지와 기존 데이터는 보존.
- 공동 일정, 기존 행사, 예배 콘티, 발행된 주간 자료, 예배 담당표를 주간/월간 캘린더에 표시.
- 종류 필터, 일정 상세, 원본 자료 링크, 관리자 일정 등록/수정.
- 표시 기간이 있는 공동 공지. 종료일 다음 날부터 노출하지 않음.
- 오늘부터 7일 예배 자료, 오늘부터 28일 주요 마감.
- 기존 내 순 출석 바로가기와 통계 유지. 출석은 뉴욕 기준 최근 주일의 입력 건수 기준으로 표시.

## 데이터와 권한

- 새 테이블: ministry_calendar, dashboard_notices. phase23-shared-dashboard.sql 적용.
- 승인 역할 admin / upper_room_leader / group_leader만 새 공유 테이블 읽기.
- 관리자만 등록/수정. 서버 작업과 데이터베이스 정책 모두 검사.
- cc_* 개인 총괄 데이터는 조회하거나 복제하지 않음.
- weekly_briefs는 발행된 제목·말씀 메타데이터만 조회. 기도/돌봄 등 본문은 공동 공지로 추출하지 않음.
- 일정 삭제 대신 취소 상태로 기록 유지. 기존 행사 연결 항목은 행사 원본에서 제목·날짜 수정.
- 명시적 event_id 연결만 행사와 합침. 이름 유사성으로 임의 병합하지 않음.
- 같은 날짜·예배 종류의 콘티/주간자료/담당표는 한 카드로 연결.
- 기존 자료 등록은 확정으로 간주하지 않고 '원본 등록' 상태로 표시.
- 일부 조회 실패는 화면 경고로 표시.
