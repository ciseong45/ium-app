# 이음채플 개인 총괄 시스템 구현 안내

구현 기준: `이음채플 개인 총괄 시스템 상세 설계도.md` v1.1
담당 관점: Ium Chapel Agent / 사역 총괄 + Media & Tech Owner
기준 시간대: `America/New_York`

## 구현 상태

설계 단계 1–4와 5단계의 검증 가능한 운영 범위를 `ium-app`의 관리자 전용 `/command-center` 화면으로 구현했다.

- 이번 주: 오늘 결과물 최대 3개, 기한 경과, 이번 주 실행, 4주 일정, 주간 점검
- 수집함: 내용 한 줄 입력, 정규화 기반 중복 방지, 원문을 유지한 업무 전환
- 사역 현황: 여섯 고정 영역, 반복 사역·교육·프로젝트 구분, 준비 상태 계산
- 일정: 잠정·확정·취소 구분, 사역 및 준비 업무 연결
- 대기·결정: 실제 요청 이력, 다음 확인일, 답변 후 진행 복귀, 결정 근거
- 자료 찾기: 초안·확정·이전 버전, 원본 위치, 완료·보관 기록 검색 및 복원
- 보안: 모든 개인 테이블을 `owner_id = auth.uid()` RLS로 격리하고 앱 화면은 관리자만 노출
- 이력·백업: 주요 레코드의 변경 전후 자동 기록, 개인 JSON 내보내기
- 반복 준비: 예배·교육·행사 양식을 회차별 한 번만 생성하고 방학·외부 진행 회차는 이유와 함께 제외
- 일정 변경: 완료 업무와 수동 기한은 보존하고 자동 생성된 미완료 기한만 상대 날짜에 맞춰 이동
- 일정 취소: 연결 업무를 자동 완료하지 않고 검토 대상으로 남기며 게시 기록은 갱신 필요로 전환
- 사람 연결: 기존 `members.id`만 참조하여 업무와 연결하고 이름·상태·최근 8주 출석 신호를 원본에서 조회
- 개인정보 경계: 전화번호·이메일·주소·메모·기도 내용은 개인 총괄에 저장하거나 조회하지 않음
- 예산·정산: 사역별·통화별로 예정·승인 금액과 실제 지급을 분리하고 공식 회계 장부와의 경계를 표시
- 학기 전환: 사역별 종료·계속·보류·취소 판단과 근거를 기록하고, 계속·보류는 다음 검토일을 요구

게시 기록과 연결표도 스키마에 포함되어 있다. 외부 카톡·메일 발송, 양방향 달력 동기화, 정기 자동 실행은 실제 필요와 알림 범위를 확인하지 않아 활성화하지 않았다.

## 데이터 기준

초기 불러오기는 다음 내부 원본만 사용한다.

- `2026 가을학기 마스터 일정.md`: 9/13–9/27 In the Beginning, 10/4 야외예배 등 확정 날짜
- `2026 가을학기 실행 대시보드.md`: 준비 업무와 결정 게이트
- `2026 In the Beginning 3주 온보딩 기획안.md`: 확정 내용과 사용자 확인 대기 항목

확정되지 않은 목적·진행 방식·장소·예산·순 시작일은 완료 기록으로 만들지 않고 결정 대기 또는 막힌 일로 넣는다. 초기 불러오기는 `source_key`를 사용하므로 다시 실행해도 중복되지 않는다.

## 활성화 순서

1. Supabase SQL Editor에서 `supabase/phase19-personal-command-center.sql`을 실행한다.
2. `supabase/phase20-command-center-recurring-preparation.sql`을 실행한다.
3. `supabase/phase21-command-center-existing-links.sql`을 실행한다.
4. `supabase/phase22-command-center-operating-expansion.sql`을 실행한다.
5. 앱 코드를 배포하거나 로컬 환경에 Supabase 연결값을 설정한다.
6. 관리자 계정으로 로그인해 사이드바의 `개인 총괄`을 연다.
7. 첫 화면의 `2026 가을 기준 불러오기`를 한 번 실행한다.
8. 일정 탭에서 회차별 준비 양식을 적용하고, 업무 카드에서 필요한 멤버만 연결한다.

## 운영 경계

- 메뉴를 숨기는 것 외에 데이터 조회·수정·검색·내보내기까지 사용자 ID로 분리한다.
- 다른 관리 기능의 멤버 개인정보를 개인 총괄 테이블로 복사하지 않는다.
- 답변 수신은 업무 완료가 아니며, 받은 답과 다음 행동을 기록해 진행 상태로 돌린다.
- 완료에는 근거가 필요하고, 삭제 대신 보관하여 복원할 수 있게 한다.
- 원본 로컬 경로는 같은 Mac에서만 유효할 수 있다. 모바일 원본 열기는 별도 저장소 연결 뒤 제공한다.
- 정기 자동 실행과 외부 발송은 설정하지 않았다.
